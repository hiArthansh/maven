I have created a progam which uses the onboard switches to control the onboard led's.
I have also altered the .xdc file so as to connect the switches in front alignment to the led'd.
Earlier they were connected in a ciss cross pattern which was vey jumbled.
On operating the switches the board also utilizes the buzzer to get the effecct of turning on and off the switches.
Buzzer uses a 0.1 sec beep at 100 Mhz frequency wave.
